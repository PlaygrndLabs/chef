Your Cloudflare access

Check or remove chef's access to your Cloudflare account

chef asks for access only while it installs or updates itself in your account. As soon as setup is done, chef deletes its copy and tells Cloudflare to revoke it. You can check that yourself, or revoke it sooner, at any time. Keep this page for later.

  1. Open Connected Applications in Cloudflare

    Sign in to Cloudflare, open your profile, then go to Access Management and Connected Applications. This link takes you straight there:

    Open Connected Applications ↗

  2. Find chef in the list

    Each app shows the permissions and the accounts you gave it. After setup has finished, chef should no longer have working access.

  3. Select Revoke

    Select Revoke in chef's row. Access ends right away. chef keeps running in your account and your projects stay as they are. Next time you install or update chef, Cloudflare simply asks you again.

The one thing setup leaves behind

To publish your previews and live apps, setup creates one API token named chef previews in your account. It can only publish Workers, nothing else. You find it under Manage Account, Account API Tokens. Delete it only if you remove chef, because previews stop working without it.

Source: Cloudflare's guide to authorizing an application.
