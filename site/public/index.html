How a build goes

One ask in. A live app out.

  1. 01

    Ask

    Say what you want in plain words. chef turns it into a spec and writes the tests before any code.

  2. 02

    Split

    chef breaks the ask into features and adds each one to your project's feature tree. Every feature gets its own session with its own copy of the code in Cloudflare Artifacts, so several features are built at the same time.

  3. 03

    Build

    Each session builds in its own sandbox with a live preview link. Previews sleep when idle and wake on the next click.

  4. 04

    Check

    Tests, type checks and an AI review must pass. Then chef merges the work into your main code for you, so you never deal with branches or merge conflicts.

  5. 05

    Live

    The latest version of your app is online at its own address. Connect GitHub only if you also want a copy of the code there.

Everything runs on Cloudflare, in your own account.

Nothing runs on your computer
No terminal, no Docker and nothing to install. Agents, sandboxes and previews run on Cloudflare's network, so your computer stays free and builds stay fast, even with many sessions running at once.
Git built for agents
Every project is a git repository in Cloudflare Artifacts, Cloudflare's git storage made for agents. Each session works on its own copy, only work that passes its checks reaches main, and any git client can clone it.
Your data stays with you
Code, previews, project memory and keys live in your Cloudflare account. chef's access to your account ends as soon as setup is done.
Bring your model
Use an Anthropic API key or any compatible provider. Keys never reach the browser or the sandbox.
Many projects
One chef runs all your projects, each with its own address, previews and settings.

Questions

Where do my code and data live?

In your Cloudflare account. Projects are git repositories in Cloudflare Artifacts, and your model keys, settings and previews stay there too. GitHub sync is optional.

What does this site keep?

Your Cloudflare user id and email, when you joined and last signed in, and the address of chef in your account with the key this site uses to reach it. Nothing else.

Does chef keep access to my Cloudflare account?

No. The access you grant at sign-in is used only while chef installs or updates itself in your account, and it ends right after. You can check or remove that access in Cloudflare any time.

What does setup create in my account?

A chef Worker for your organization with its Durable Objects, a container image for its sandboxes, a Vectorize index for project memory, an Artifacts namespace for your repositories, and one API token limited to Workers scripts so chef can publish previews. Everything is yours to inspect or remove.

Which Cloudflare plan do I need?

Workers Paid, because chef uses Containers and Artifacts. If your account is on the free plan, the setup page links you to the upgrade.
